what is prism

prism is a macos external for roblox. it attaches to the roblox and gives you a full control: local player modifiers, aimbot, esp, a live instance explorer, server functions, player info, server info, fflag customization and font customization.

installation
prism is macos only. no windows support is planned.
requirements
  • 1
    macOS 13 Ventura or later. older versions are not tested and likely won't work.
  • 2
    Roblox installed. prism attaches to the roblox process. it needs to be running before you launch prism.
  • 3
    Apple Silicon or Intel. both are supported. Apple Silicon (arm64) releases first.
download

prism is not publicly available yet. the install script will be posted here and in the discord at launch. though when it's posted, paste it into terminal and follow the prompts.

only download prism from this page or the official discord (https://discord.gg/prismmacos). third-party links are not affiliated and could be malicious.
first launch

prism is not signed, so Gatekeeper will block it on first launch. open terminal and paste xattr -c /path/to/prism to bypass the warning.

quickstart
  • 1
    Open Roblox and join a game.
  • 2
    Launch Prism. the status indicator on the home tab says "attached" when it's attached. if it says "not attached", make sure Roblox is open.
  • 3
    Pick a panel from the sidebar and toggle what you want. changes apply immediately.
  • 4
    Check the Console tab if something is not working. errors surface there.
home tab

the home tab shows your prism version, current Roblox version, macOS version, architecture, attach status, session uptime, and the current game name. below that is a player list, click any player to see their username, user ID, account age, and team.

local player
everything in this tab is detected by most game's anticheat. use it on accounts you're willing to lose.
toggles
Noclip
lets your character pass through walls and floors. toggle on/off at any time.
Infinite Jump
removes the jump cooldown so you can jump repeatedly
sliders
settingdefaultrangenotes
Walkspeed1616 to 100roblox default is 16. values above ~32 are very obvious to other players.
Jump Power5050 to 100roblox default is 50.
Gravity1960 to 360roblox workspace default is 196. set to 1 for floaty movement.

hit Reset to restore all three values to their defaults without reattaching.

aimbot & esp
aimbot
Enable Aimbot
only locks onto players inside the fov circle.
Target Head
when on, locks to players heads. when off, locks to the torso of the player.
aimbot settings
settingdefaultrangenotes
Fov radius12020 to 400size of the aim circle on screen in pixel, players outside the circle are ignored.
Smoothness51 to 201 is instant snap. 20 is very smooth. higher=look more human.
Fov circle color#3D7DFCany hexset via the color swatch or type a hex value directly.
esp
Player Boxes
draws a bounding box around each player's character.
Distance Labels
shows the stud distance from your character to each visible player.
Tracers
draws a line from a fixed point on your screen to each player. positions: middle, bottom, or top of screen (configurable via dropdown).
esp labels
Show Player Namedisplay username shown above the player.
Show Healthshows health bar ontop of players.
color modes

esp supports two color modes. team colors automatically colors each player based on their current team color. custom color uses one color you pick, applied to all players.

explorer

the explorer panel reads the instance tree from the current game you're in and auto-refreshes. if you're not in a game it waits and shows a status overlay. switching games resets and repopulates the tree automatically.

using the explorer
  • 1
    Join a game in Roblox, the explorer stays blank until you're in a game.
  • 2
    Click one to select it and see its info, click the arrow to expand children.
  • 3
    Use the search bar to filter by name.
  • 4
    Click Refresh to refresh?? 😭
server functions
all server functions require prism to be attached.
available functions
Rejoin Server
rejoins the exact same server using the current Job ID.
ServerHop
leaves the current server and joins a different server in the same game.
Join Server
This joins a specific game/server by taking a required place id and an optional job id
game information
info about the current roblox game.

all info populate automatically once prism is attached. click any value to copy it.

fielddescription
Game Namedisplay name of the current roblox experience. click to copy.
Place IDunique numeric ID of the current place. used by server functions.
Universe IDparent game/universe ID, distinct from the Place ID.
Creator IDuser or group ID of the game creator.
Job IDunique server instance id. used by rejoin server.
player list

the home tab includes a player list. if the game has teams, a scroll bar thingy filters by team. click any player row to open a detail popup with their display name, username, user ID, account age, and current team.

customization
roblox font replacement and prism theme controls.
font replacement

prism can replace roblox's font with a custom font, restart roblox after applying any font change.

Import Custom Font
import a .ttf or .otf file. imported fonts are saved to a library and can be applied or deleted anytime.
Restore Default Font
removes any custom font and restores roblox's original. restart roblox after restoring.
font status shows whether a custom font is active, if it says "custom font active" a restore button appears.
config profiles

config profiles save your entire settings state (toggles, sliders, colors, FFlags, theme) under a name. create profiles with the + button, overwrite existing ones, load, or delete. you can also export a config to a file and import it on another mac (so u can share to others whatever works for you in specific games).

faq
common questions.
is prism free?
yes. prism is completely free. no paid tiers, no premium version.
when is it releasing?
no confirmed date. join the discord to get notified when it drops.
macOS is blocking the app
sudo xattr -c /path/to/prism (sudo is optional)
can I get banned?
Externals on macOS are undetected by default, assuming you do not use any risky features such as local player modifications. (local player wont get you banned from roblox but instead the game you use it in depending on the anticheat)
local player features are detected?
no. everything in the local player wont get you banned from roblox but instead the game you use it in depending on the anticheat.
does it work on Apple Silicon?
yes. prism runs natively on any m-chip mac. Intel macs will also be supported. Apple Silicon ships first.
prism shows "not attached"
make sure Roblox is open and you're inside a game, not just on the menu. if it still won't attach, restart both Roblox and Prism. if it persists, report it in the discord.
